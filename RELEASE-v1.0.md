# EVE Mining 1.0

Created by Marcel Ijonen [NO.W8].

Download **EVE-Mining-1.0.zip**, extract all files and start **EVE-Mining.exe**.
An English Quick setup is included and appears on a fresh installation.

- Multi-character Ice and Ore cargo tracking
- Fleet profiles, compression detection and cargo ETA
- Janice BUY price import; 186 dated default BUY prices included
- Incoming-attack sound, critical-yield highlighting and activity hints
- Automatic session pause / resume

Requires Windows PowerShell 5.1 and .NET Framework 4.8.
No personal character profiles or session data are included.
